<task type="auto">
  <name>Implement message codec with JSON/MessagePack selection</name>
  <files>
    packages/coordination/src/communication/codec.ts
  </files>
  <action>
    Create `packages/coordination/src/communication/codec.ts`:

    Export functions:
    1. shouldUseMessagePack(payload: unknown): boolean
       - Returns true if serialized size > 1024 bytes (1KB threshold)
       - Implements check by trying JSON.stringify and checking length

    2. encodeMessage(envelope: MessageEnvelope): Buffer
       - Checks if shouldUseMessagePack(envelope.payload)
       - If true: encodes payload with msgpackr, marks envelope.codec = 'msgpack'
       - If false: JSON.stringify payload, marks envelope.codec = 'json'
       - Returns Buffer with encoded envelope

    3. decodeMessage(buffer: Buffer): MessageEnvelope
       - Parses envelope JSON
       - If envelope.codec === 'msgpack': decodes payload with msgpackr
       - If envelope.codec === 'json': JSON.parse payload
       - Returns MessageEnvelope

    Per HARD-05: Message payloads over 1KB use MessagePack for efficiency.
    Per RESEARCH.md: MessagePack is 3.5x faster than JSON, 15-50% smaller.

    DO NOT implement custom binary format (use msgpackr per RESEARCH.md).
  </action>
  <verify>
    grep -E "shouldUseMessagePack|encodeMessage|decodeMessage" packages/coordination/src/communication/codec.ts
  </verify>
  <done>
    Message codec selects MessagePack for payloads over 1KB
  </done>
