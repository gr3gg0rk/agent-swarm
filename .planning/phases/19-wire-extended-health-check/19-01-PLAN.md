## Verification

After all tasks are complete, verify the extended health check is working:

1. Build the coordination package:

   ```bash
   npm run build
   ```

2. Start the API server:

   ```bash
   npm run api
   ```

3. In another terminal, test the health endpoint:
   ```bash
   curl -s http://localhost:3000/health | jq .
   ```

Expected response should include all three checks:

```json
{
  "status": "healthy" | "degraded" | "unhealthy",
  "checks": {
    "imports": { "status": "pass" },
    "database": { "status": "pass" },
    "mqtt": { "status": "pass" | "skip" }
  },
  "timestamp": "..."
}
```

If MQTT is not configured or broker not running, the status should be "degraded" with mqtt check showing "skip".
