Create systemd/openclaw-mqtt.service with the following specifications per CONTEXT.md locked decisions:

**[Unit] section:**

- Description: "OpenClaw Swarm MQTT Broker"
- Documentation: Link to repository (use placeholder https://github.com/your-repo/openclaw-swarm)
- After=network-online.target
- Wants=network-online.target

**[Service] section:**

- Type=notify (Mosquitto supports sd-daemon notification)
- NotifyAccess=main
- ExecStart=/usr/sbin/mosquitto -c /etc/mosquitto/mosquitto.conf
- ExecReload=/bin/kill -HUP $MAINPID
- Restart=always
- RestartSec=5s
- StartLimitInterval=10s
- StartLimitBurst=5
- StandardOutput=journal
- StandardError=journal

**[Install] section:**

- WantedBy=multi-user.target

**DO NOT include:**

- User/Group directives (left empty per Claude's discretion)
- Resource limits (none per CONTEXT.md decision)
- WorkingDirectory (not needed for mosquitto)

**Rationale:** Type=notify allows systemd to track when Mosquitto is actually ready. ExecReload enables config reload without restart. Restart limits prevent crash loops per CONTEXT.md decisions.
</action>
