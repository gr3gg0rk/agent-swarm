    1. start(): void
       - Set checkInterval = setInterval(() => this.check(), config.checkIntervalMs)

       - Clear checkInterval if set

       - Get stats via this.getMemoryStats()
       - Determine action via this.shouldThrottle(stats)
       - Call throttleController.throttle(stats) if action is pause
       - Call throttleController.recover(stats) if action is resume

       - const v8Stats = v8.getHeapStatistics() (import v8 from 'node:v8')

    5. private shouldThrottle(stats: MemoryStats): ThrottleAction
       - Return 'pause_non_critical' if stats.usagePercent >= config.thresholdPercent
       - Return 'resume' if stats.usagePercent < config.resumeThresholdPercent
       - Return 'none' otherwise

    Create packages/coordination/src/memory/throttle.ts with ThrottleController class:

    Constructor:
    - taskQueue: TaskQueue
    - config: ThrottleConfig
    - pausedTasks: Set<taskId>
    - logger: Logger

    Methods:
    1. throttle(stats: MemoryStats): void
       - Log warning: "Memory at ${(stats.usagePercent * 100).toFixed(1)}%, pausing tasks"
       - Get active tasks via taskQueue.getTasks({ status: 'in_progress' })
       - For each task:
         - Skip if already in pausedTasks
         - If task.priority < config.priorityThreshold (non-critical):
           - Update task status to 'paused'
           - Add to pausedTasks set
           - Log info: "Paused non-critical task ${task.id}"
       - After pausing: if global.gc exists, call global.gc() to request garbage collection
       - Per CONTEXT.md locked decision: "Throttle action: pause in-progress tasks to free memory, resume when pressure decreases."

    2. recover(stats: MemoryStats): void
       - Return immediately if pausedTasks.size === 0
       - Check if stats.usagePercent < config.resumeThresholdPercent (80%)
       - If true: log "Memory recovered to ${(stats.usagePercent * 100).toFixed(1)}%, resuming tasks"
       - For each taskId in pausedTasks:
         - Get task via taskQueue.getTask(taskId)
         - If task exists and task.status === 'paused':
           - Update task status to 'pending' (re-queue for execution)
           - Log info: "Resumed task ${task.id}"
       - Clear pausedTasks set
       - Per CONTEXT.md locked decision: "Resume when pressure decreases."

    3. getPausedTaskCount(): number
       - Return pausedTasks.size

    Per CONTEXT.md locked decision: "Graceful degradation: prefer pausing over killing, checkpoint before stopping if possible."
    Per RESEARCH.md pattern: "Pause only non-critical tasks (priority < 100). Request GC with global.gc()."

    Note: Task pausing integrates with WorkerTaskExecutor - paused tasks have status='paused', workers check status before executing.
  </action>
