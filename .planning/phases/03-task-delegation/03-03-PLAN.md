  <action>
    Create packages/coordination/src/delegation/retry.ts with RetryManager class:
    - Constructor: taskQueue (TaskQueue), timeoutMonitor (TimeoutMonitor)
    - Private properties: taskQueue, timeoutMonitor, activeRetries (Map<string, number>)

    - shouldRetry(error: Error, retryCount: number, maxRetries: number): boolean
      * Calls classifyError(error) from timeout.ts
      * Returns false if errorType === 'permanent' (abort immediately)
      * Returns false if retryCount >= maxRetries (exhausted retries)
      * Returns true if errorType === 'transient' and retryCount < maxRetries

    - calculateBackoff(retryCount: number): number
      * Base delay: Math.pow(2, retryCount) * 1000 (1s, 2s, 4s, 8s...)
      * Jitter: Math.random() * 1000 (0-1s random)
      * Capped: Math.min(baseDelay + jitter, 30000) (max 30s)
      * Returns calculated delay in milliseconds

    - async scheduleRetry(taskId: string, error: Error): Promise<void>
      * Gets task from TaskQueue
      * Throws Error if task not found
      * Extracts retryCount (task.retryCount || 0) and maxRetries (task.maxRetries || 3)
      * Checks shouldRetry(error, retryCount, maxRetries)
      * If should not retry: calls notifyExhausted() and returns
      * If should retry:
        - Calculates backoff delay with calculateBackoff(retryCount)
        - Increments retryCount: newRetryCount = retryCount + 1
        - Updates task in TaskQueue: updateTaskRetry(taskId, newRetryCount)
        - Updates task status to 'pending' for re-dispatch
        - Stores in activeRetries map: taskId -> newRetryCount
        - Logs retry message with delay

    - cancelRetry(taskId: string): void
      * Removes taskId from activeRetries map if present

    - private async notifyExhausted(taskId: string, error: Error): void
      * Creates TaskResult with success: false, error type, message
      * Publishes notification to Minerva via guidance request or dedicated topic
      * Logs exhaustion message

    - getActiveRetryCount(): number
      * Returns activeRetries.map.size

    - isRetrying(taskId: string): boolean
      * Returns activeRetries.has(taskId)

    Follow CONTEXT.md decision: "Auto-retry first: timed out tasks automatically retry with exponential backoff + jitter"
    Follow CONTEXT.md decision: "Minerva notified after exhaustion: orchestrator only notified after max retries exhausted"
    Follow CONTEXT.md decision: "Per-task retry limit: task creator sets max retries at delegation (no fixed limit)"
    Follow RESEARCH.md pattern: Exponential backoff with jitter per AWS guidance

    DO NOT create actual retry execution - just the scheduling and decision logic. DO NOT create Minerva notification system - just stub the notification call.
  </action>
