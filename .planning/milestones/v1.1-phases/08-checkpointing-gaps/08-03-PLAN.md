<objective>
Implement state reconciliation and vector clock ordering for cross-machine checkpoint recovery.

**Purpose:** Blindly overwriting current state with checkpoint state causes progress regression and data loss. Field-level reconciliation merges intelligently (MAX for progress, merge for partial results). Vector clocks enable accurate checkpoint ordering across machines with clock skew, rejecting stale checkpoints while accepting concurrent updates.

**Output:** Vector clock system with hybrid (wall clock + counter) design, state reconciliation with field-specific merge strategies, and ResumeLogic integration for intelligent recovery.

Per 08-CONTEXT.md: Timestamp-based merge - newer timestamps win on field-by-field basis. Progress: Take MAX(checkpoint progress, current progress). Partial results: Merge both sets. On incompatible states: Restart task from scratch. Hybrid vector clocks: Wall clock timestamp + counter per machine. Reject older checkpoints, accept newer or concurrent.

Per 08-RESEARCH.md: Add VectorClock type and comparison logic. Extend CheckpointData with vectorClock field. Add reconcileCheckpoint() method to ResumeLogic. Implement field-level merge with timestamp-based conflict resolution.

</objective>

       - `tick(): VectorClock` - increments this machine's counter, updates timestamp to Date.now(), returns clone
       - `merge(other: VectorClock): void` - merges another clock (takes MAX of each counter), updates timestamp to max
       - `compare(other: VectorClock): VectorClockComparison` - standard vector clock comparison algorithm:
         * Check all machines in both clocks
         * If all counters <= and at least one <, return 'before'
         * If all counters >= and at least one >, return 'after'
         * If neither condition met (some <, some >), return 'concurrent'
         * If all equal, return 'equal'
       - `isNewerOrConcurrent(other: VectorClock): boolean` - returns true if comparison is 'after' or 'concurrent'
       - `clone(): VectorClock` - returns deep copy of clock
       - `toJSON(): object` - returns { timestamp, counters: Object.fromEntries(counters) }
       - `static fromJSON(json: object, machineId: string): VectorClockImpl` - deserializes JSON, returns new instance
